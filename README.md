This CNN Toolbox demonstrates the effect of following parameters on convolutional neural layers

Number of Strides
Number of Kernels
Number of filters
Number of layers
Number of Dropout layers
Dropout probability
Different Activation functions
Types of padding( None, Zero padding, One padding)
Types of pooling (None, Max pooling, Min pooling)

Feel free to experiment with different values of Strides, kernels, filter , layers, types of padding, pooling and see how it affects the convolutional neural network
